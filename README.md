# Qthing（轻想）

> 为移动端而生的极简笔记 —— 本地 Markdown 存档，自建同步，无负担记录

---

## 🌱 项目愿景

**Obsidian 的理念，移动端的体验**

Qthing 是一个轻量级移动端笔记应用，继承 Obsidian 的核心哲学 —— **本地 Markdown 存档**，但彻底重构移动端体验：

- ✅ **打开即写**：启动 <1 秒，无任何干扰元素
- ✅ **数据主权**：笔记以 `.md` 格式本地存储，可直接访问
- ✅ **自建同步**：简单账号系统，无需配置 WebDAV/CouchDB
- ✅ **分端异构**：移动端专注快速记录，桌面端用 Obsidian 全量管理

---

## 🎯 解决什么问题？

| 痛点 | Qthing 的答案 |
|------|---------------|
| Obsidian 移动端太重 | 只保留「新建 + 编辑」核心功能，无双链/图谱/插件负担 |
| 同步配置复杂 | 账号密码登录，一键同步，无需懂 WebDAV/CouchDB |
| 数据锁在云端 | 笔记始终存于本地，后端仅作同步中转 |
| 想用但怕折腾 | 极简设计，3 分钟配置，专注记录本身 |
